# Base comum de fontes

A base ativa é **R1**, descrita integralmente em [bases/R1.md](bases/R1.md).
Leia esse arquivo antes de executar uma feature. Ele fixa SHAs, hashes, campanha
candidata, decisões D01–D08 e cobertura dos compromissos do TCC1.

O experimento continuará evoluindo. R1 é um recorte de trabalho, e não um estado
final obrigatório da pesquisa. O arquivo de cada base é preservado; este índice
aponta para a base escolhida para novas entregas. Entregas anteriores conservam
a identidade da base realmente utilizada.

Para incorporar novos commits, siga o [fluxo de evoluções](EVOLUCOES.md) usando
`tcc2-evoluir`. A próxima base recebe outro ID e seu próprio arquivo em `bases/`.
Atualize este índice apenas na preparação coordenada da rodada, antes de distribuir
redatores. Não altere o recorte de agentes já em execução.

A estrutura editorial vigente está no [plano de redação](../docs/plano-redacao.md).
Uma mudança de capítulos não exige outra base experimental quando as fontes
permanecem iguais.
